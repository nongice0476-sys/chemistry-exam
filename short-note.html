1) Atomic Structure

อนุภาคพื้นฐาน

Z = โปรตอน
A = p + n → n = A − Z
อะตอมกลาง: e = Z
ไอออนบวก: e = Z − charge
ไอออนลบ: e = Z + |charge|

Photon

c = λν
E = hν = hc/λ
E สูง ↔ ν สูง ↔ λ สั้น
nm → m: ×10⁻⁹

Hydrogen

ΔE = −2.18×10⁻¹⁸[1/nf² − 1/ni²] J
n ลง = emission • n ขึ้น = absorption
พลังงาน photon ใช้ |ΔE|

Quantum / Electron config

l = 0…n−1; ml = −l…+l; ms = ±1/2
จำนวน orbital = 2l+1
s=1, p=3, d=5, f=7 orbitals
Paramagnetic = มี e เดี่ยว • Diamagnetic = จับคู่หมด

จุดพลาด: ΔE ของอะตอมตอน emission อาจติดลบ แต่พลังงาน photon เป็นค่าบวก

2) Periodic Table & Atomic Properties

สมบัติ→ ในคาบ↓ ในหมู่
Atomic radiusลดเพิ่ม
Ionization energyโดยรวมเพิ่มลด
Electronegativityเพิ่มลด

Isoelectronic

e เท่ากัน → Z มากกว่า → ดึงแรงกว่า → รัศมีเล็กกว่า
Al³⁺ < Mg²⁺ < Na⁺ < F⁻

Effective nuclear charge

Zeff = Z − S
Zeff มาก → e ถูกดึงแรงขึ้น

ข้อยกเว้น IE

Al เอา e จาก 3p ง่ายกว่า Mg จาก 3s → IE(Al) < IE(Mg)

Average atomic mass

Σ(isotope mass × fractional abundance)
% ต้องหาร 100 ก่อน

3) Chemical Bonding

ชนิดพันธะ

โลหะ + อโลหะ → ionic
อโลหะ + อโลหะ → covalent
สูตร ionic: ผลรวมประจุ = 0

VSEPR

2 domains → linear
3 → trigonal planar
4 → tetrahedral e-geometry
4 + 1 lone pair → trigonal pyramidal
4 + 2 lone pairs → bent

Polarity

ดู bond dipole → geometry → เวกเตอร์หักล้างไหม
CO₂ nonpolar • H₂O polar

IMF

London: ทุกโมเลกุล
Dipole–dipole: polar
H-bond: H ติด N/O/F
IMF แรง → bp สูง, vapor pressure ต่ำ

MO Theory

Bond order = (Nbonding − Nantibonding)/2
O₂ paramagnetic เพราะมี e เดี่ยวใน π*

จุดพลาด: พันธะมีขั้ว ≠ โมเลกุลมีขั้วเสมอ ต้องดูรูปร่าง

4) Stoichiometry

Workflow 5 ขั้น

  1. ดุลสมการ
  2. given → mol
  3. ใช้ mole ratio
  4. mol → หน่วยที่ถาม
  5. เช็ก sig figs/หน่วย

สูตรพื้นฐาน

n = mass / molar mass
M = mol / L solution
M₁V₁ = M₂V₂
%yield = actual/theoretical ×100

Limiting reagent

อย่าเทียบ mol ดิบตรง ๆ → เทียบตาม coefficient หรือคำนวณ product ที่แต่ละ reactant ให้ได้

Empirical → Molecular

% → สมมติ 100 g → mol → หารค่าน้อยสุด → ratio
factor = molar mass / empirical formula mass

จุดพลาด: Molarity ใช้ L ของสารละลาย ไม่ใช่ solvent

5) Liquid & Solution

Vapor Pressure / Boiling

IMF แรง → vapor pressure ต่ำ → bp สูง
Psolvent = Xsolvent P°solvent
ΔP = P° Xsolute (nonvolatile solute)

Molality

m = mol solute / kg solvent
ใช้ kg solvent ไม่ใช่ kg solution

Colligative

ΔTf = iKfm
ΔTb = iKbm
i = จำนวนอนุภาคหลังแตกตัวตามสมมติฐานโจทย์

Osmotic Pressure

π = iMRT

Quick check: เติม nonvolatile solute → vapor pressure ↓, boiling point ↑, freezing point ↓, osmotic pressure ↑
